# LeadPal × FeedPlay Integration Prototype

Interactive prototype of the LeadPal lead-capture overlay running inside the FeedPlay video player.
Built for Awesome Impacts LLC (FeedPlay) under the approved LeadPal integration proposal.

- Static site: `index.html`, `style.css`, `app.js`. No build step.
- Hosted on Netlify from the `main` branch (the shared preview link).
- Prototype only: no lead data leaves the browser.
